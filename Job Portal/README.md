# Job Portal

A web-based job portal developed as part of the CODSOFT internship projects.

## Features

- User registration and login
- Job listings and job search
- Candidate dashboard
- Recruiter dashboard
- Admin dashboard
- Job application management
- Saved jobs
- Resume upload and management
- Company listings

## Tech Stack

- Next.js
- React
- TypeScript
- Prisma
- Database integration

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/amangupta0711/CodSoft_Tasks.git
```

### 2. Open the Job Portal folder

```bash
cd "CodSoft_Tasks/Job Portal"
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file using `.env.example` as a reference. Add the required configuration values.

Do not upload real credentials or secrets to GitHub.

### 5. Configure the database

Set up the database connection and follow the Prisma configuration in the project.

### 6. Run the development server

```bash
npm run dev
```

Open the local URL shown in your terminal.

## Project Structure

- `app/` — Application pages and API routes
- `components/` — Reusable UI components
- `lib/` — Utilities and application logic
- `prisma/` — Database schema and seed files
